# Academic-CV
This is a free template of academic CV that you may use.

A professional CV website built using HTML and CSS.

This project presents my educational background,
professional experience, research interests,
technical skills, and achievements in a clean
and responsive layout.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Features

- Clean and professional CV layout
- Responsive design for different screen sizes
- Education and professional experience sections
- Research and digital skills
- Academic portfolio and achievements
- Print-friendly A4 layout
- Clickable GitHub and LinkedIn links

## Project Structure

    My-CV/
    - Academic_CV.html
    - style.css
    - README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `Academic_CV.html` in a web browser.
4. Explore the CV.

No additional libraries or installations
are required.
